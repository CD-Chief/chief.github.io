Hi 👋 I'm Chief-Daniel Osei, a passionate software engineering student at Newcastle University with a deep fascination for all things tech.

My journey into the world of engineering began during my early school years, where I was constantly interested in how the devices and software around me worked. This curiosity naturally drew me to computer science, a subject I pursued throughout my education. Since then, the subject has developed into a lifelong passion and I am now studying software engineering and working towards becoming a professional in the field.

I discovered my love for programming when I started learning Python at school, which inspired me to work on personal projects at home. During my International Baccalaureate (IB), I expanded my knowledge with Java, which quickly became my favourite high-level language. During this time, I also dabbled in web development and learnt Lua while working on a video game project with friends. Since then, my studies have further developed my skills and given me the opportunity to learn new languages such as Bash, Go and C.

Currently, I am focusing on diversifying my portfolio and gaining professional experience in the industry. One of my recent goals was to master React, a popular web development framework, although I have always had a preference for backend development. Stepping outside of my comfort zone has helped me understand web technologies and I am now able to work seamlessly in both frontend and backend environments.

I am always keen to connect with like-minded people, whether they are developers, employers or just people interested in technology. If you would like to exchange ideas or collaborate with me, please don't hesitate to contact me!

Conway's Game of life

A mathematical simulation exploring cellular automata, developed as part of a research essay. This Java-based implementation allows users to manually configure game states or generate random patterns, analyzing how different setups evolve over time. The project highlights the intersection of mathematics and computer science while demonstrating fundamental programming concepts.

Key Features

  • Manual & Random Input: Users can define custom starting states or let the program generate random configurations.
  • Automated Data Collection: The program records outcomes to analyze different patterns.
  • Efficient Rule Implementation: Handles survival, death, and reproduction rules using structured logic.

Challenges

  • Abstracting the game’s mechanics into functional code (~350 lines).
  • Implementing complex rule-based logic with nested loops and conditionals.
  • Ensuring accurate data collection for research purposes.

Outcome

  • Successfully demonstrated how programming can be used for mathematical research.
  • Gained insights into Conway’s Game of Life and refined problem-solving skills.
  • Strengthened ability to translate theoretical concepts into working code.

Future Improvements

  • Implementing a graphical user interface (GUI) for better visualization.
  • Optimizing performance for larger grid sizes and longer simulations.
  • Exploring multi-threading for improved efficiency.

AI Hunter

This project, AI Hunter, was developed during my first hackathon in Sheffield as part of a team of four. The idea I proposed was an AI that adapts to the player's movements and actions while trying to catch them. Although we had plans for additional mechanics, such as items (e.g., flashbangs) to create gaps between the player and the AI, we were only able to implement the AI’s adaptive chasing behavior within the hackathon timeframe.

We built the project in Python using PyTorch and Pygame. It was our first time using these technologies, and for most of us, our first hackathon experience.

Key Features

  • AI Pathfinding & Adaptation: The AI learns from the player's movement patterns and adjusts accordingly.
  • Real-time Pursuit Mechanics: The AI dynamically chases the player based on learned behaviors.
  • Built with Python, Pygame, and PyTorch: Used for game logic, rendering, and AI learning respectively.

Challenges

  • Skill-Level Variations: As we were unfamiliar with each other’s abilities, task allocation was initially difficult. However, I was able to assess our strengths over time, which helped improve our workflow.
  • Git Workflow Issues: We encountered confusion with Git pushes and merges, which led to conflicts. This was resolved by establishing a structured Git workflow.
  • First-Time Use of Pygame & PyTorch: We had to learn both libraries on the spot, which slowed development but was a valuable learning experience.
  • Task Delegation: I realized the importance of overseeing everyone’s progress to prevent bottlenecks where someone was waiting too long for dependent code.

Outcome

  • Successfully built a working AI that adapts and chases the player.
  • Learned how to collaborate efficiently in a hackathon setting with limited time.
  • Gained experience with Python, PyTorch, Pygame, and Git version control in a team environment.
  • Improved my ability to delegate tasks and ensure that teammates weren’t blocked by dependencies.

Future Improvements

  • Implementing items and mechanics to help players evade the AI, such as flashbangs or obstacles.
  • Enhancing the AI learning algorithm for more sophisticated adaptations.
  • Improving the game visuals and UI for a better player experience.
  • Refining team coordination and Git workflow for smoother collaboration in future projects.

Blog Website

This blog website project was an assignment that involved showcasing various computer security practices, including authentication, encryption, and event logging. The app was built using Flask and utilized SQLite for database storage, including user information and event logs. It was my first experience with Flask and Bootstrap, and I learned a lot throughout the process by integrating these technologies.

Key Features

  • Authentication & Authorization: Implemented user login, registration, and authorization with RBAC.
  • Strong Password Enforcement: Ensured passwords are hashed and required to meet security standards.
  • Multi-Factor Authentication (MFA): Added an extra layer of security for user accounts.
  • CAPTCHA & Input Validation: Prevented spam and ensured valid input from users.
  • Event Logging: Stored important actions and events in the database for tracking.
  • Symmetric Encryption: Used encryption to protect sensitive data in the application.

Challenges

  • Learning Flask: This was my first experience with Flask, so it required time to understand its structure and functionality.
  • Database Integration: Setting up SQLite to store user data, passwords (hashed), and event logs was challenging, especially while ensuring security.
  • Integrating Multiple Security Features: Combining authentication, MFA, RBAC, encryption, and input validation required careful attention to detail.
  • Learning Bootstrap: Implementing a responsive layout with Bootstrap was new and required research and experimentation.

Outcome

  • Successfully developed a fully functional blog website with security features such as authentication, encryption, and event logging.
  • Gained hands-on experience with Flask, Bootstrap, and SQLite, which are now essential tools in my web development toolkit.
  • Delivered a secure web application that incorporated several best practices for computer security.

Future Improvements

  • Hosting the website online for broader access.
  • Adding a distinguishing factor to make the blog stand out from other similar websites.
  • Enhancing the UI and functionality to make the blog more interactive and user-friendly.
